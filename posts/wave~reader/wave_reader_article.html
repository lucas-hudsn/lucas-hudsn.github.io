Introduction

wave~reader is a simple agentic web application designed to well informed beach descriptions, surf forecast and daily surf report to a user by leveraging AI-powered analysis and real-time meteorological data. Built with a sophisticated multi-agent architecture, the application synthesizes wave data, wind patterns, and geographic information to deliver actionable insights for surfers.

Project Vision

The core vision of wave~reader is to democratize access to professional-grade surf forecasting through an intuitive, accessible interface. Rather than requiring users to interpret raw meteorological data or consult multiple sources, the application presents curated, AI-generated forecasts that consider complex interactions between ocean conditions, wind patterns, and geographic factors.

This current implementation is only a proof of concept, I am planning on building out more rigid features into the website with the hope of hosting and maintaining it when I feel it is ready.

Key Features

  • Multi-Agent Architecture: Four specialized agents working in concert
  • Real-Time Data Integration: Live marine and weather data from Open-Meteo
  • AI-Generated Forecasts: GPT-4o-mini powered analysis and predictions
  • Interactive Visualizations: Charts and geographic maps for data exploration
  • Minimal Frontend: Pure HTML/CSS/JavaScript with no build tools required
  • Lofi Aesthetic: Thoughtfully designed user interface with earthy color palette

Technology Stack

Backend

  • Python 3.14 with uv package manager for fast, deterministic dependency management
  • FastAPI 0.128.0: Modern async web framework with automatic API documentation
  • LangGraph 0.2.0: Multi-agent orchestration framework for coordinating specialized agents
  • LangChain 0.3.0: LLM integration layer with OpenAI GPT-4o-mini
  • Jinja2 Templates: Server-side template rendering for dynamic HTML generation

Frontend

  • HTML5: Semantic markup with accessibility considerations
  • CSS3: Custom lofi aesthetic with earthy color palette and block-style design
  • Vanilla JavaScript: No frameworks; minimal dependencies for maximum control
  • Chart.js 4.4.0: Progressive enhancement for data visualization

Data Sources

  • Open-Meteo Marine API: Wave height, period, and direction (hourly & daily aggregates)
  • Open-Meteo Weather API: Wind speed and direction at 10m elevation
  • OpenAI API: GPT-4o-mini for description generation and forecast synthesis

The Four-Agent Pipeline

Agent 1: Description Generator

Purpose: Gather contextual information about the requested beach Functionality: - Accepts beach name from user input - Uses GPT-4o-mini to generate rich descriptions - Considers geographic, cultural, and surfing context - Returns formatted description text

Input: Beach name (string)

Output:

{
  "description": "Bells Beach is a legendary...",
  "context": "Historical and cultural information"
}

Agent 2: Coordinate Resolver

Purpose: Convert beach names to precise geographic coordinates

Functionality: - Takes beach name and description context - Uses GPT-4o-mini with coordinate-resolution prompting - Validates coordinate ranges (±90° latitude, ±180° longitude) - Handles ambiguous beach names through context

Input: Beach name + description context

Output:

{
  "latitude": -38.1734,
  "longitude": 144.3994,
  "beach_name": "Bells Beach, Victoria"
}

Agent 3: Weather Data Fetcher

Purpose: Retrieve real-time swell and wind data from dual APIs

Functionality: - Makes two separate API calls (critical architectural decision): - Marine API (marine-api.open-meteo.com/v1/marine): - Wave height (meters) - Wave period (seconds) - Wave direction (degrees)

  • Weather API (api.open-meteo.com/v1/forecast):
    • Wind speed at 10m (km/h)
    • Wind direction (degrees)
  • Merges hourly data from both sources
  • Computes daily maximum values
  • Includes proper error handling with graceful fallbacks

Input: Latitude, Longitude

Output:

{
  "latitude": -38.1734,
  "longitude": 144.3994,
  "timezone": "Australia/Melbourne",
  "wave_height_max": 2.8,
  "wave_period_max": 12.3,
  "wind_speed_max": 18.5,
  "wind_direction": 270,
  "hourly": {
    "time": ["2026-01-13T00:00", "2026-01-13T01:00", ...],
    "wave_height": [1.2, 1.3, 1.4, ...],
    "wave_period": [10.5, 10.6, 10.7, ...],
    "wave_direction": [265, 267, 269, ...],
    "wind_speed": [15.2, 15.8, 16.1, ...],
    "wind_direction": [268, 269, 270, ...]
  }
}

Agent 4: Forecast Synthesizer

Purpose: Create human-readable forecast text using AI analysis

Functionality: - Accepts all weather data and beach context - Prompts GPT-4o-mini for professional forecast generation - Considers: - Wave conditions (height, period, direction) - Wind patterns and their effect on conditions - Optimal surfing windows - Safety considerations
